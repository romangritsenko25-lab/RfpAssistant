# Данные / Data

**Все данные в этой папке вымышленные.** Компания «Степлайт Технолоджиз» (Steppelight Technologies LLP, Астана),
её заказчики, сертификаты, цифры и контакты придуманы для демонстрации. Номера сертификатов не приводятся,
домены и телефоны — заглушки. Совпадения с реальными организациями случайны.

*All data here is fictional: the company, its customers, certificates, figures and contacts are invented for a demo.*

## Состав

| Путь | Что это |
|---|---|
| `kb_src/` | 40 исходных документов: Markdown с YAML-шапкой (`title, section, language, effective_date, format, doc_id`). Единственный источник правды для базы знаний |
| `kb/` | Результат сборки: те же 40 документов в целевых форматах (13 DOCX, 12 PDF, 4 XLSX, 11 MD) и `manifest.json` с метаданными и SHA-256 |
| `sets/dev/` | Dev-набор для настройки (исходник — `src/questions.json`): `questionnaire.xlsx` (40 вопросов, колонки `ID, Domain, Question, Answer`), `rfp.docx` (15 пронумерованных требований среди обычного текста), `gold.jsonl` (эталоны) |

Языки базы знаний: 19 документов на русском, 11 на английском, 10 на казахском. Темы: услуги и технологии,
политики ИБ, процессы разработки и поддержки, 7 кейсов, сертификаты, SLA.

## Как собрана база знаний

```
uv run python scripts/build_kb.py [--src data/kb_src] [--out data/kb] [--font C:\Windows\Fonts\arial.ttf]
```

Скрипт читает `kb_src/*.md` и по полю `format` пишет `kb/<doc_id>.<format>`:

- DOCX — заголовки в стилях Heading 1/2, списки и таблицы; метаданные в свойствах документа;
- PDF — reportlab с текстовым слоем; нужен TTF-шрифт с кириллицей и казахскими буквами (`--font`, по умолчанию Arial);
  метаданные в информации PDF;
- XLSX — по листу на раздел, таблицы с заголовками колонок;
- MD — копия исходника.

Сборка детерминирована (даты внутри файлов равны дате актуальности, ZIP-контейнеры упакованы с постоянным временем):
повторный запуск даёт те же байты и те же хэши в `manifest.json`.

## Намеренные противоречия

Для проверки статуса «требует проверки» и выбора актуального документа в базе два расхождения:

1. **RPO/RTO:** `SEC-004` (01.06.2023) — RPO 4 ч, RTO 8 ч; `SEC-003` (15.04.2026) — RPO 1 ч, RTO 4 ч.
2. **Время реакции на P1:** `SLA-001` (01.02.2024) — 30 минут; `SUP-002` (10.02.2026) — 15 минут.

Это не ошибки данных, не «исправляйте» их.

## Dev-набор и эталоны

`gold.jsonl` — по строке на вопрос: `id`, `file`, `question`, `language`, `answerable`, `gold_answer`,
`sources` (`doc_id` + заголовок раздела) и `conflict` (вопрос на противоречивые факты).
Всего 55 вопросов (40 + 15): ru 27, kk 15, en 13; без ответа в базе — 11 (20%); на противоречия — 2 (`Q-010`, `R-003`).
У вопросов без ответа `gold_answer = null`, `sources = []`.

Источник вопросов, эталонов и раскладки RFP — `sets/dev/src/questions.json`. Пересборка:

```
uv run python scripts/build_dev_set.py [--src data/sets/dev/src/questions.json] [--out data/sets/dev]
```

Скрипт детерминирован: повторный запуск даёт те же байты. Если меняете `kb_src/`, проверьте, что заголовки
разделов в `questions.json` совпадают с заголовками `##` в исходниках.

## Пересобрать всё

```
uv run python scripts/build_kb.py
uv run python scripts/build_dev_set.py
```

Отложенный тест-набор лежит отдельно и не относится к этой папке; при настройке поиска и промптов его не используют.
