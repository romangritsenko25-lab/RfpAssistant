# Сроки хранения журналов и данных

## Сроки хранения

| Тип данных | Срок хранения | Место хранения | Примечание |
|---|---|---|---|
| Журналы аудита доступа | 12 месяцев | Система SIEM | Неизменяемое хранение |
| Журналы приложений | 90 дней | Централизованный стек журналов | Для отладки и расследований |
| Записи привилегированных сессий | 12 месяцев | Защищённое хранилище PAM | Только для службы ИБ |
| Записи об инцидентах ИБ | 3 года | Система учёта инцидентов | Включает отчёты разбора |
| Результаты пересмотра прав доступа | 3 года | Система учёта заявок | Ежеквартальный пересмотр |
| Ежедневные резервные копии | 35 дней | Астана, реплика в Алматы | Шифрование AES-256 |
| Ежемесячные резервные копии | 12 месяцев | Астана, реплика в Алматы | Шифрование AES-256 |

## Мониторинг

Мониторинг событий безопасности ведёт собственный центр мониторинга (SOC) в режиме 24x7, в составе шести аналитиков. Время на всех серверах синхронизируется по протоколу NTP с двумя независимыми источниками.

## Удаление данных заказчика

После завершения договора данные заказчика удаляются из производственных систем в течение 30 дней, из резервных копий — по истечении их срока хранения. По запросу выдаётся письменное подтверждение удаления.
