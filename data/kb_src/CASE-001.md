# Кейс — мобильный и онлайн-банкинг для «Сарыарка Финанс»

## Заказчик и задача

«Сарыарка Финанс» — вымышленная финансовая организация. В 2023 году ей потребовалось заменить устаревший интернет-банкинг на новую платформу с мобильным приложением для физических лиц. Проект выполнялся с марта 2023 по апрель 2024 года, длительность — 14 месяцев.

## Решение

Серверная часть построена на Java 21 и Spring Boot по микросервисной архитектуре, 23 сервиса в Kubernetes. Мобильное приложение разработано на React Native для Android и iOS, веб-версия — на React. В качестве базы данных использован PostgreSQL, обмен событиями — через Kafka. Интеграция с процессинговым центром и системой быстрых платежей выполнена через защищённые API.

## Команда

В проекте участвовали 18 специалистов: 9 разработчиков, 4 инженера по тестированию, 2 DevOps-инженера, аналитик, дизайнер интерфейсов и руководитель проекта.

## Результаты

К концу 2024 года приложением пользовались 1,2 миллиона клиентов. Платформа выдерживает нагрузку до 1200 транзакций в секунду. Фактическая доступность за первые 12 месяцев эксплуатации составила 99,95%. Среднее время ответа API на 95-м процентиле — 310 миллисекунд.
