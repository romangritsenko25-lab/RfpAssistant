# Жизненный цикл разработки (SDLC)

## Этапы

Разработка проходит шесть этапов: сбор требований, проектирование, реализация, верификация, выпуск и эксплуатация. Переход между этапами фиксируется в Jira, результаты каждого этапа согласуются с заказчиком.

## Безопасность в процессе разработки

На этапе проектирования для новых систем и значительных изменений выполняется моделирование угроз. На этапе реализации действуют правила безопасного кодирования на основе OWASP ASVS. Перед выпуском обязательны статический анализ кода и проверка сторонних библиотек.

## Методология

Основная методология — Scrum со спринтами по 2 недели. Для проектов с жёстко заданным объёмом применяется гибридный подход: этап проектирования выполняется по плану, реализация — спринтами. В репозитории используются короткоживущие ветки, основной поток — trunk-based development.

## Определение готовности

Задача считается выполненной (Definition of Done), если код прошёл рецензирование, автоматические тесты успешны, покрытие нового кода тестами не ниже 80%, документация обновлена, а проверки безопасности в конвейере не выявили критических замечаний.

## Документирование

Для каждого проекта ведутся: описание архитектуры, API-спецификация в формате OpenAPI, руководство по развёртыванию и журнал архитектурных решений (ADR). Документация хранится в Confluence и передаётся заказчику при приёмке.
