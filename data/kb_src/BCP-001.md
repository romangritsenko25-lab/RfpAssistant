# План обеспечения непрерывности бизнеса

## Область действия

План охватывает критичные процессы компании: сопровождение производственных систем заказчиков, службу поддержки, центр мониторинга и разработку. Для критичных систем целевое время восстановления (RTO) составляет 4 часа.

## Резервная площадка

Резервная площадка находится в Алматы. Там размещены реплики данных и подготовленная инфраструктура для переключения. Переключение на резервную площадку решает технический директор по рекомендации руководителя эксплуатации.

## Кризисная команда

В кризисную команду входят: генеральный директор, технический директор, руководитель эксплуатации, руководитель службы ИБ и руководитель службы поддержки. Заместители назначены для каждой роли. Сбор команды при инциденте уровня S1 — не позднее 1 часа с момента принятия решения.

## Работа сотрудников при недоступности офиса

При недоступности офиса в Астане сотрудники переходят на удалённую работу через защищённое подключение с обязательной MFA. Все 280 сотрудников обеспечены корпоративными ноутбуками с шифрованием дисков.

## Проверка плана

Учение по аварийному восстановлению проводится один раз в год, настольное учение — два раза в год. По итогам составляется отчёт с перечнем улучшений и сроками их выполнения.
