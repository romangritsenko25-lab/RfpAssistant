# Кейс — портал онлайн-записи для сети клиник «Нұр Медикал»

## Заказчик и задача

«Нұр Медикал» — вымышленная сеть из 26 клиник в 9 городах Казахстана. Задача — единый портал и мобильное приложение для записи на приём, получения результатов анализов и оплаты услуг. Проект выполнялся с сентября 2024 по июль 2025 года, длительность — 11 месяцев.

## Решение

Серверная часть написана на C# (.NET 8), веб-клиент — на React, мобильные приложения — на Flutter. Данные хранятся в PostgreSQL в центре обработки данных в Астане, все медицинские данные шифруются алгоритмом AES-256. Для входа используется двухфакторная аутентификация. Интерфейс доступен на русском и казахском языках.

## Интеграции

Портал интегрирован с медицинской информационной системой клиник, с платёжным шлюзом и с сервисом SMS-уведомлений. Обмен с медицинской системой ведётся по стандарту HL7 FHIR.

## Результаты

За первые три месяца после запуска через портал выполнено более 300 000 записей в месяц, доля записей через приложение составила 58%. Количество звонков в колл-центр сократилось на 41%. Доступность портала в первые шесть месяцев — 99,9%.
